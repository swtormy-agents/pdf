# Privacy notice

HTML version: https://noclaudkit.com/pdf/privacy.html

**No uploads.** Your PDF files and images are opened, combined, split and saved inside your browser. Files and file names are not sent to any server. The page's Content-Security-Policy restricts network connections to this site's own origin, and the tool makes no network requests with your files.

**Self-hosted code.** All scripts, including the PDF libraries (pdf-lib, pdf.js) and the pdf.js worker, are served from this same site. No third-party CDNs, fonts or trackers.

**No cookies, no analytics, no ads, no accounts.** We do not collect personal data. PDFs often contain personal data; because they never leave your device, we do not receive or process it.

**Theme setting.** The only thing this site stores in your browser is your theme choice (Light or Dark), kept locally in localStorage under the key `lic-theme`. It is never sent anywhere and is not a cookie. Choosing System removes it; you can also clear it by clearing this site's data in your browser.

**Metadata.** By default the saved PDF does not keep the document's Author, Title, Subject, Keywords or XMP metadata, and the "Producer" field is set to a neutral value. EXIF data and location are removed from the photos.

**Protected PDFs.** Password-protected or restricted PDFs are not unlocked. If a file is protected, remove the protection in software where you have the rights to do so, then try again.

**Hosting logs.** The site is hosted on GitHub Pages. GitHub, as the host, may log technical data such as visitor IP addresses for security and operation; see the [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). We do not receive or use these logs.

Questions: [open an issue in the GitHub repository](https://github.com/swtormy-agents/pdf/issues).
