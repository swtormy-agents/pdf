隐私声明

不上传。 您的 PDF 文件和图片均在您的浏览器内打开、合并、拆分和保存。文件和文件名不会发送到任何服务器。页面的内容安全策略（Content-Security-Policy）仅允许与本站自身的源（origin）建立网络连接，本工具不会发起任何携带您文件的网络请求。

自托管代码。 所有脚本（包括 PDF 库 pdf-lib、pdf.js 及 pdf.js 工作线程）均由本站提供。不使用第三方 CDN、字体或跟踪器。

无 Cookie、无分析、无广告、无账户。 我们不收集个人数据。PDF 文件常含有个人数据；由于文件不会离开您的设备，我们不会接收或处理这些数据。

主题设置。 本站在您的浏览器中存储的唯一内容是您的主题选择（浅色或深色），保存在浏览器 localStorage 中，键名为 lic-theme。它不会被发送到任何地方，也不是 Cookie。选择“跟随系统”会将其删除；您也可以在浏览器中清除本站数据来删除它。

元数据。保存的 PDF 始终是一个新文档，不含文档信息（作者、标题、主题、关键词、生成程序、日期），也不含 XMP 元数据。JPEG 图片中的元数据会被删除，包括 EXIF（含 GPS 位置信息）、XMP、IPTC 和注释；这适用于您 PDF 页面中的图片以及通过“JPG 和照片转 PDF”添加的照片。PNG 图片只保留像素数据。显示页面所需的数据会被保留，其中可能包含附带信息，例如嵌入的字体（可能含有字体作者的姓名）、ICC 颜色配置文件，以及 JPEG 2000 图片和内嵌（inline）图片中的元数据。页面的文字和内容不会被更改。

受保护的 PDF。 本工具不会解除 PDF 的密码保护或使用限制。如文件受保护，请在您有权操作的软件中解除保护后再试。

托管日志。 本站托管在 GitHub Pages 上。GitHub 作为托管方，可能出于安全和运营目的记录访问者 IP 地址等技术数据；请参阅《GitHub 隐私声明》（英文）。我们不接收也不使用这些日志。

如有疑问，请在 GitHub 仓库中提交 issue。
